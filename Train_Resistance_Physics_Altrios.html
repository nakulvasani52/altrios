Train Resistance Physics in Altrios

Overview

Altrios calculates train resistance forces using the Modified Davis Equation, which determines how much resistive force acts against a train's motion. This resistance directly impacts fuel consumption because the locomotive must generate enough power to overcome these forces.

The Complete Resistance Formula

The complete train resistance formula is:

R = A + BV + CV² + 20G + 0.8c

Where:

  • R = total resistance in lbs per ton
  • A = rolling resistance (constant)
  • B = bearing/mechanical resistance coefficient
  • V = velocity (speed)
  • C = aerodynamic drag coefficient
  • G = grade in percent
  • c = curvature in degrees

Code Location

All resistance calculations are located in:

altrios-core/src/train/resistance/

This directory contains:

  • kind/ - Individual resistance component implementations
  • method/ - Methods for combining resistances (Point vs Strap)
  • mod.rs - Main resistance trait and wrapper

Resistance Components Breakdown

1. Rolling Resistance (A term)

Physics: Constant resistance from wheel-rail contact, independent of speed.

Code File: rolling.rs

F_rolling = ratio × weight

Typical value: 1.5 lb/ton

2. Bearing Resistance (part of A term)

Physics: Constant friction from axle bearings.

Code File: bearing.rs

F_bearing = constant force

Typical value: 4,000 lbf (40 cars × 100 lbf)

3. Davis B Term (BV term)

Physics: Speed-dependent mechanical resistance, linear with velocity.

Code File: davis_b.rs

F_davis_b = B × velocity × weight

Typical value: 0.03 (lb/ton)/(mph)

4. Aerodynamic Resistance (CV² term)

Physics: Air drag, proportional to velocity squared.

Code File: aerodynamic.rs

F_aero = C_d × A × ρ_air × velocity²

Where:

  • C_d × A = drag coefficient × frontal area
  • ρ_air = air density
Note: The traditional factor of 0.5 in the drag equation is lumped into the coefficient.

5. Grade Resistance (20G term)

Physics: Gravitational force component pulling the train down (or up) a slope.

Code File: path_res.rs

F_grade = grade × weight

Physics derivation:

  • F_G = W × sin(A) where A is slope angle
  • For small angles: sin(A) ≈ tan(A) = G (grade)
  • Result: F_G = W × G
  • For 1% grade: F_G = 0.01W = 20 lbs per ton
Key insight: The "20G" in the formula means 20 pounds per ton per percent grade.

6. Curve Resistance (0.8c term)

Physics: Additional resistance from wheel flanges rubbing against rails on curves.

Code File: path_res.rs (same as grade resistance)

F_curve = curve_coeff × weight
Note: The "0.8c" means 0.8 pounds per ton per degree of curvature.

How Resistances Are Combined

All resistance forces are summed to get total net resistance:

Code File: train_state.rs (res_net function)

res_net = res_rolling + res_bearing + res_davis_b + res_aero + res_grade + res_curve

This matches the formula: R = A + BV + CV² + 20G + 0.8c

Where:

  • A = res_rolling + res_bearing
  • BV = res_davis_b
  • CV² = res_aero
  • 20G = res_grade
  • 0.8c = res_curve

Connection to Fuel Consumption

The total resistance force determines the power required to maintain speed:

Power = Force × Velocity

The locomotive must generate this power, which directly translates to fuel consumption:

  • Higher resistance → More power needed → More fuel burned
  • Grades and curves dramatically increase resistance
  • Speed affects aerodynamic (V²) and Davis B (V) terms significantly

Example Calculation

Scenario: 100 loaded 110-ton cars (143 tons each loaded) at 10 mph on 0.76% grade and 6-degree curve

Calculation breakdown:

  • A term (rolling + bearing): ~18,700 lbs (from straight, level track)
  • BV term: Minimal at 10 mph
  • CV² term: Very small at 10 mph
  • 20G term: 20 × 0.76 × 14,300 tons = ~217,000 lbs
  • 0.8c term: 0.8 × 6 × 14,300 tons = ~68,600 lbs

Conclusion: The grade and curve terms dominate at low speeds on challenging terrain!

Summary

Altrios implements the complete Modified Davis Equation for train resistance. Each term is calculated separately and summed to get total resistance. This total resistance force determines the power requirement, which directly drives fuel consumption calculations. The modular design allows each resistance component to be independently configured and validated.
